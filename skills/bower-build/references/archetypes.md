# Slide Archetypes — the build menu

Pick the archetype that fits the **action title**, never the data shape. The title is the
claim; the archetype is the apparatus for proving it.

## Choosing from the title

| The title claims… | Archetype |
|---|---|
| One number is the whole story | Big number / factoid |
| X is bigger/smaller than Y | Sorted horizontal bar |
| X changed over time | Line (many points) / column (few) |
| We got from A to B because of… | Waterfall |
| X is __% of the whole | Stacked column or sorted bar |
| Option B is best | Comparison table (criteria rows × option columns) |
| These N things must happen | MECE bucket list / numbered list with side panel |
| Items sit on two dimensions | 2×2 matrix or scatter |
| Here's the sequence | Process chevron / value chain / timeline |
| Status of N workstreams | Traffic light / RAG table |
| Someone said something that matters | Quote (≤2 per deck) |
| The whole argument on one page | Executive summary |

## The core archetypes

**Executive summary (slide 2, always).** Action title = the governing thought. Body = the Key
Line points, 3–5, one sentence each, in the same words as the section titles. No chart, no
decoration. The most important slide in the deck.

**Single-chart slide.** Title bar → optional framing line → exhibit at ~65–75% of canvas built
to its spec → source bottom-left, page number bottom-right. Must pass the McCandless read:
(1) the chart can be named; (2) obvious questions answered on the slide (axes, units, period,
n); (3) the action title states the insight; (4) the proving data points are highlighted,
everything else grey; (5) the takeaway sets up the next slide.

**Bullet-supported insight.** 3–4 bullets, parallel grammar (same part of speech), each
expanding one piece of the title's claim. Groups of ≥2 (a single bullet is prose — write it as
plain text). One idea per bullet, ≤2 lines, one sub-level max. **No clotheslines:** 5+ parallel
items get grouped into labelled groups (3 groups of 2 beat 1 list of 6).

**Comparison table.** Options as columns, criteria as rows, criteria in order of importance;
drop any criterion where all options score the same; recommended option highlighted. The
natural body for To B or Not to B.

**2×2.** Both axes labelled with what increases; quadrants labelled or blank; title states the
conclusion the matrix supports.

**MECE bucket list.** 3–5 boxes: category, one-liner, key metric. Usually right after the exec
summary — it introduces the framework the deck then walks.

**Options matrix (deductive decks).** Criteria as rows listed BEFORE the reveal, options as
columns including "do nothing" priced, recommendation column in accent, footnote: "What would
change our mind: ___".

**Roadmap/Gantt.** 2–4 phases, 2–4 milestones each, owner on every milestone, dependencies
marked, no gratuitous gridlines.

**Ask slide.** Decision / owner / date, verbatim from the brief. Nothing competes with it.

## Structural slides (G## rows)

**Cover:** deck title (SMART, present participle), client, sub-headline, date, team. No page
number, no source. **Agenda:** ≤5 short items, action verbs, visually ignorable titles; the
current section highlighted on re-shows. **Section divider:** short label + the section's Key
Line sentence verbatim as the one-line promise. **Closing:** key takeaways (1–4, numbered) +
next steps (action + owner · timing). **Appendix separator.**

Navigation for decks >10 slides: tracker markers per slide (act/section, bottom-right area);
detail pages structured as a visible double-click into an element of their parent page; action
titles may open with the framework words introduced on the structure page.

## Layout discipline

**Every slide is a table:** rows = items, columns = dimensions (measure / rationale / impact /
timing). Three shapes cover almost everything — qualitative (text table), quantitative (one
chart + a methodology/implication column), integrated (text rows + a data column). Adjust only
when a framework demands its own shape.

**Build order per slide — never start with the visual:** 1 message (= the title, verbatim) →
2 layout (rows × columns) → 3 main visual (from the exhibit spec) → 4 supporting text (parallel
grammar, ≥2 per group, ≤5 per box) → 5 polish (alignment, consistency, no jitter).

**Density:** one concept per slide · 90-second read ceiling · if it feels full, split it ·
appendix (X##) may be denser — it is reference material at scale.read.
